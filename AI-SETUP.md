# Proxy Tunnel — инструкция для нейросети-помощника

Этот файл написан для нейросети (ChatGPT, DeepSeek, Claude, GigaChat, Алиса и любой другой), которую человек
попросил помочь установить и настроить Proxy Tunnel. Если вы — нейросеть, ведите человека по шагам ниже.
Если вы человек — скопируйте нейросети фразу из раздела «Настроить с помощью нейросети» в [README.md](README.md).

## Как вести разговор

- **Один шаг за раз.** Дайте один шаг, дождитесь ответа «готово» или вопроса, затем следующий. Не вываливайте
  всю инструкцию сразу.
- **Простые слова.** Собеседник, скорее всего, не программист. Называйте кнопки и надписи точно так, как они
  написаны в программе, — в кавычках-ёлочках: «Настроить сервер».
- **Спрашивайте, что на экране.** Если что-то пошло не так, попросите переписать красную надпись или прислать
  снимок экрана, а потом найдите её в разделе «Если что-то не так».
- **Пароль от сервера — только в программу.** Никогда не просите прислать пароль, адрес с паролем или ключи
  в чат. Пароль вводится в окно программы, она его нигде не сохраняет.
- **Терминал не нужен.** Программа сама всё ставит на сервер. Не предлагайте команды для терминала, правку
  системных настроек прокси или файлов вручную — это ломает то, что программа делает сама. Исключение —
  раздел «Вручную» в настройках программы, и только если автоматическая настройка не прошла (шаг 3).
- Если вы агент с доступом к компьютеру (Claude Code, Codex, Cursor и т. п.): можно скачать установщик и
  открыть его, предупредив человека. Ничего не делайте на сервере сами и не входите на него по ssh — это
  работа программы.

## Что это за программа (чтобы отвечать на вопросы)

- Программа для Mac (macOS 13 или новее) и Windows 10/11. Соединяет компьютер с **собственным сервером
  человека за границей** и отправляет через него только Claude (сайт claude.ai, приложение Claude, Claude Code
  в VS Code и в терминале) и сайты из списка. Всё остальное — банки, почта, видео — работает напрямую.
- Бесплатная, с открытым кодом. Платить нужно только за сервер (хостингу).
- На сервер ставится маленький прокси, доступный только через защищённое соединение по ключу. Никакие чужие
  сервисы в цепочке не участвуют.
- Важно знать: пока туннель включён, Claude Code ходит только через него. Если сервер перестал отвечать,
  Claude Code тоже не отвечает — тогда туннель выключают нажатием на карточку или выходят из программы.

## Шаг 0. Узнать главное

Спросите:

1. Mac или Windows? (На Mac — узнать версию: меню  → «Об этом Mac»; нужна macOS 13 Ventura или новее.)
2. Есть ли уже свой сервер за границей с Ubuntu или Debian, и известны ли его адрес (несколько цифр через
   точку, например `203.0.113.10`) и пароль пользователя `root`?

Есть сервер — к шагу 2. Нет — шаг 1.

## Шаг 1. Сервер (если его нет)

- Подойдёт любой зарубежный сервер (VPS) у любого хостинга: система **Ubuntu** или **Debian**, самый дешёвый
  тариф. Страна — та, где Claude работает: например, Германия, Нидерланды, Финляндия, США.
- В программе есть кнопка «Нет сервера? Арендовать» — ссылка на хостинг, который проверен с программой. Можно
  взять и любой другой.
- После оплаты хостинг присылает (обычно на почту) **адрес сервера** и **пароль пользователя root**. Пусть
  человек найдёт это письмо и держит под рукой, но в чат не присылает.
- Некоторые хостинги просят сменить пароль при первом входе. Если позже программа скажет «Сервер требует
  сменить пароль при первом входе», нужно один раз войти через консоль в личном кабинете хостинга, задать
  новый пароль и вернуться в программу.

## Шаг 2. Скачать и установить

**Mac**

1. Скачать: https://github.com/cookiespooky/proxy-tunnel/releases/latest/download/ProxyTunnel-mac.dmg
2. Открыть скачанный файл, перетащить значок «Proxy Tunnel» в папку «Программы».
3. Первый запуск: в «Программах» правый щелчок по «Proxy Tunnel» → «Открыть» → «Открыть». Если такой кнопки
   нет — попробовать открыть, затем «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно
   открыть». Программа не подписана сертификатом Apple, поэтому macOS переспрашивает — это ожидаемо.
4. Значок появится вверху справа, рядом с часами. Окна в Dock у программы нет.

**Windows**

1. Скачать: https://github.com/cookiespooky/proxy-tunnel/releases/latest/download/ProxyTunnel-windows.exe
2. Запустить. Если появится «Система Windows защитила ваш компьютер» — «Подробнее» → «Выполнить в любом
   случае». Причина та же: у программы нет платной подписи.
3. Значок появится внизу справа у часов; если его не видно — нажать стрелку «^» рядом с часами.

## Шаг 3. Первая настройка (один раз)

1. При первом запуске откроется окно «Настройки Proxy Tunnel». Если не открылось — щелчок по значку →
   «Настроить туннель…» (или значок шестерёнки / «Настройки»).
2. Раздел «Сервер»: вписать адрес сервера. Подождать пару секунд.
3. Если появится «Вашего ключа на сервере нет — войдите логином и паролем от сервера»: логин `root` (уже
   вписан), пароль — из письма хостинга. Галочку «Создать ключ для входа…» оставить включённой — тогда пароль
   больше не понадобится.
4. Нажать «Настроить сервер» и подождать минуту-две, пока все пункты не станут зелёными. Программа сама
   поставит всё на сервер и включит туннель.
5. Если автоматически не получается (например, хостинг пускает только через свою веб-консоль): вкладка
   «Вручную» → «Создать ключ туннеля» (если такая кнопка есть) → «Скопировать команду для сервера» → вставить
   команду в консоль сервера в личном кабинете хостинга → Enter → дождаться строки «сервер готов» → вернуться
   в программу и нажать «Сохранить» внизу окна.

## Шаг 4. Включить и проверить

1. Щелчок по значку программы. Верхняя карточка — это выключатель: нажать на «Туннель выключен».
2. Ниже появятся проверки: «Туннель подключён», «Выход через туннель», «Claude Code → туннель», «Сайты из
   списка → туннель». Все должны стать зелёными.
3. Успех — надпись «Claude — через туннель» на карточке и сообщение «Туннель включён для Claude».
4. **Закрыть и снова открыть** Claude Code (VS Code или терминал), приложение Claude и браузер, если они были
   открыты: уже запущенные программы не видят новые настройки.
5. Проверка глазами: открыть https://claude.ai — сайт должен открыться и пустить войти.

При каждом запуске программа стартует с выключенным туннелем — включать нажатием на карточку, когда нужно.
Чтобы программа запускалась вместе с компьютером, в настройках есть переключатель «Запускать при входе».

## Шаг 5. По желанию

- **Выключить вход по паролю** — сервер станет защищённее, программа продолжит входить по ключу. Настройки →
  раздел «Доступ к серверу» → «Выключить вход по паролю» (кнопка доступна, когда вход по ключу подтверждён;
  подтвердить — «Проверить соединение»).
- **Добавить сайты.** Настройки → «Через туннель»: адрес сайта отдельной строкой (например, `example.com`) →
  «Сохранить» → перезапустить браузер. Если сайт открывается не полностью, добавить и адреса, с которых он
  грузит картинки и остальное.
- Список действует на браузеры и приложения, которые берут сетевые настройки из системы. Терминальные утилиты
  и некоторые расширения VS Code со своими настройками сети его не учитывают. Claude Code идёт через туннель
  целиком и без списка.

## Обновления и статистика

- Раз в день программа проверяет новую версию. Если в её окне есть строка «Доступна версия…» — нажать
  «Скачать», закрыть программу (Настройки → «Выйти из Proxy Tunnel») и поставить новую так же, как в шаге 2
  (на Mac — согласиться заменить старую). Настройки и ключи сохраняются.
- Вместе с проверкой программа отправляет анонимную статистику: случайный номер установки, версию, систему и
  включали ли сегодня туннель. Адрес сервера, список сайтов и IP не отправляются и не сохраняются. Если человек
  не хочет её отправлять — Настройки → галочка «Отправлять анонимную статистику».

## Если что-то не так

Сначала — что написано под красным пунктом в окне программы: там сказано, что случилось и что сделать.
Подробности — в журнале: значок программы → «Журнал» (Mac: `~/Library/Logs/Proxy Tunnel.log`, Windows:
`%APPDATA%\Proxy Tunnel\log.txt`). Можно попросить прислать последние строки журнала — в нём нет паролей.

| что на экране | что сделать |
|---|---|
| «Укажите адрес сервера» | вписать адрес в раздел «Сервер» |
| «Сервер не отвечает по ssh: проверьте адрес и порт.» | проверить адрес по письму хостинга; убедиться в личном кабинете, что сервер включён |
| «Сервер отклонил подключение…» | подождать полминуты и нажать «Проверить» — сервер ограничивает число подключений подряд |
| «Сервер ограничивает частоту подключений — жду 30 секунд…» | ничего, программа повторит сама |
| «Вход не прошёл: неверный логин, пароль или ключ.» / «Пароль не подошёл.» | перепроверить пароль из письма хостинга; если меняли пароль — ввести новый |
| «Сервер требует сменить пароль при первом входе…» | войти через консоль в кабинете хостинга, сменить пароль, вернуться и ввести новый |
| «Ключ сервера изменился (сервер переустановлен?)…» | если сервер переустанавливали — Настройки → «Дополнительно» → «Забыть ключ сервера» → повторить. Если не переустанавливали — остановиться и выяснить у хостинга |
| «Выход через туннель» красный | сервер отвечает, но выход идёт не из той страны — проверить, что сервер зарубежный; «Переподключить» |
| «Claude Code → туннель» красный | выключить и снова включить туннель; перезапустить Claude Code |
| «Система не применяет PAC туннеля» / «В системе включён ещё и обычный прокси…» | на компьютере работает другая программа, которая пропускает весь интернет через себя; выключить её или её режим, который не пускает в интернет мимо неё, затем «Переподключить» |
| Claude Code перестал отвечать | щелчок по значку: туннель включён и всё зелёное? Если нет — выключить туннель нажатием на карточку и перезапустить Claude Code |
| Программа закрылась неожиданно | просто запустить снова — при запуске она сама возвращает настройки как были |
| Туннель перестал работать после переустановки сервера | Настройки → «Настроить заново…» |

Если ничего не помогло — предложите написать разработчику (ссылки ниже) и приложить последние строки журнала.
