# Proxy Tunnel

Небольшая программа для Mac и Windows. Она соединяет ваш компьютер с вашим собственным сервером за границей
и отправляет через него Claude и сайты, которые вы выберете. Остальное — напрямую.

## Настроить с помощью нейросети

Можно не читать эту страницу, а попросить нейросеть провести вас по шагам — ChatGPT, DeepSeek, Claude,
GigaChat или любую другую, которая умеет открывать ссылки. Скопируйте ей:

```text
Прочитай инструкцию https://raw.githubusercontent.com/cookiespooky/proxy-tunnel/main/AI-SETUP.md
и помоги мне по ней установить и настроить Proxy Tunnel. Веди по одному шагу и жди моего ответа.
```

Если нейросеть не открывает ссылки, откройте [AI-SETUP.md](AI-SETUP.md), скопируйте весь текст и вставьте ей
вместе с этой просьбой. Пароль от сервера нейросети не присылайте — он вводится только в окно программы.

## Что понадобится

- Компьютер с macOS 13 или новее либо с Windows 10 или 11.
- Свой сервер за границей с Ubuntu или Debian. Если сервера нет, в программе есть кнопка «Арендовать сервер».
  После аренды хостинг пришлёт адрес сервера (несколько цифр через точку) и пароль от пользователя `root` —
  они понадобятся один раз, при первой настройке.

## Установка

**Mac**

1. Скачайте программу по ссылке в конце страницы и откройте скачанный файл.
2. Перетащите значок «Proxy Tunnel» в папку «Программы».
3. Первый запуск: в «Программах» щёлкните по «Proxy Tunnel» правой кнопкой мыши → «Открыть» → «Открыть».
   Если такой кнопки нет: попробуйте открыть программу, затем зайдите в «Системные настройки» →
   «Конфиденциальность и безопасность» и нажмите «Всё равно открыть».

Значок программы появится вверху экрана, справа, рядом с часами.

**Windows**

1. Скачайте программу по ссылке в конце страницы и запустите скачанный файл.
2. Если Windows покажет окно «Система Windows защитила ваш компьютер», нажмите «Подробнее» →
   «Выполнить в любом случае».

Значок программы появится внизу справа, рядом с часами. Если его не видно, нажмите на маленькую стрелку «^»
рядом с часами.

## Первая настройка (один раз)

1. При первом запуске откроется окно настроек. Впишите адрес сервера.
2. Подождите пару секунд. Если программа напишет «Вашего ключа на сервере нет», введите логин `root` и пароль
   от сервера. Галочку «Создать ключ для входа…» оставьте — тогда пароль больше не понадобится.
3. Нажмите «Настроить сервер» и подождите минуту-две, пока все пункты станут зелёными.

Программа сама всё установит на сервер. Пароль она нигде не сохраняет.

Когда всё готово, в разделе «Доступ к серверу» можно нажать «Выключить вход по паролю» — так сервер будет
защищён надёжнее, а программа продолжит входить на него сама.

## Как пользоваться

- **Включить:** щёлкните по значку программы и нажмите на верхнюю карточку «Туннель выключен». Зелёный значок
  и надпись «Claude — через туннель» — всё работает.
- После включения закройте и снова откройте Claude Code (в VS Code или в терминале) и браузер, если они были
  открыты.
- **Выключить:** снова нажмите на верхнюю карточку. При выходе из программы всё тоже возвращается как было.

При каждом запуске программа начинает с выключенного состояния — включайте, когда нужно.

## Обновления

Раз в день программа проверяет, вышла ли новая версия. Если вышла, в её окне появится строка «Доступна версия…»
с кнопкой «Скачать». Сначала закройте программу (Настройки → «Выйти из Proxy Tunnel»), затем поставьте новую
так же, как первую: на Mac перетащите значок в «Программы» и согласитесь заменить, на Windows запустите скачанный
файл вместо старого. Настройки и ключи сохранятся.

## Статистика

Чтобы автор видел, сколькими людьми программа пользуется, вместе с проверкой обновлений она сообщает случайный
номер установки (он не связан с вашим компьютером), версию программы, систему (Mac или Windows) и включали ли
сегодня туннель. Адрес вашего сервера, список сайтов и что-либо о ваших действиях в интернете не отправляются,
IP-адреса не сохраняются. Выключить — галочка «Отправлять анонимную статистику» в настройках; проверка обновлений
останется.

## Что идёт через сервер

- **Claude** — сайт claude.ai, приложение Claude, Claude Code в VS Code и в терминале. Ничего дополнительно
  настраивать не нужно. Claude Code можно отправить напрямую галочкой «Claude Code» в настройках.
- **Сайты из списка.** Список — в настройках, раздел «Через туннель». Чтобы добавить сайт, впишите его адрес
  (например, `example.com`) отдельной строкой и нажмите «Сохранить». Если сайт открывается не полностью,
  добавьте и адреса, с которых он подгружает картинки и остальное. После изменения списка может понадобиться
  перезапустить браузер.
- **ChatGPT и Gemini в браузере** — сайты chatgpt.com, openai.com, gemini.google.com и aistudio.google.com есть в
  списке; программа сама добавит их и тем, у кого она стояла раньше. Если ChatGPT открывается без картинок или не
  до конца, проверьте, что в списке есть `oaistatic.com` и `oaiusercontent.com`. Gemini в браузере грузится ещё и с
  общих адресов Google: если он открывается не до конца или пишет, что недоступен в вашей стране, добавьте
  `google.com`, `googleapis.com` и `gstatic.com` — тогда через сервер пойдут и поиск, и почта Google.
- **Codex и Gemini в терминале** (на Mac) — команды `codex` и `gemini` идут через сервер целиком, пока туннель
  включён, — даже если запущена программа, которая пускает весь интернет компьютера через себя. Ничего набирать не нужно: программа вписывает несколько строк в настройки
  терминала (`~/.zshrc`). Работает в окнах терминала, открытых после установки программы. У каждой команды своя
  галочка в настройках, обе включены; снимете обе — строки уберутся. На Windows пока так: запускайте их при включённом
  туннеле командой `$env:HTTPS_PROXY="http://127.0.0.1:8888"; codex` (или `gemini`).
- **VS Code** (на Mac) — раздел «VS Code» в настройках, обе галочки сначала выключены:
  - «Codex в VS Code» — расширение Codex идёт через сервер. Программа пишет одну строку в настройки VS Code;
    это служебная настройка расширения и может перестать работать после его обновления — проверка в программе
    это покажет. После включения перезапустите VS Code.
  - «Весь VS Code» — через сервер идёт всё, что делает VS Code: любые расширения (Gemini, Copilot и другие), их
    загрузка, команды в его терминале. Действует, если открыть VS Code из Dock при включённом туннеле; выключили
    туннель при открытом VS Code — он останется без сети до перезапуска.

  Claude Code в VS Code идёт через сервер и без них.
- **Всё остальное** работает напрямую, как без программы.

Список действует на браузеры и приложения, которые берут сетевые настройки из системы. Если запущена программа,
которая пускает весь интернет компьютера через себя, система список не применяет, и браузер идёт через ту
программу — программа Proxy Tunnel об этом скажет. Программы со своими настройками сети (например, расширения для
VS Code или утилиты в терминале) список не учитывают. Claude Code, а на Mac ещё `codex` и `gemini` в терминале идут
через сервер и в этом случае.

## Если что-то не так

- В окне программы под красным пунктом написано, что случилось и что сделать.
- «Сервер отклонил подключение» сразу после настройки — подождите полминуты и нажмите «Проверить».
- Claude Code перестал отвечать — проверьте, что программа запущена и туннель включён, либо выключите туннель
  и перезапустите Claude Code.
- Программа закрылась неожиданно — просто запустите её снова: при запуске она сама наводит порядок.
- Подробности о работе программы — в журнале: значок программы → «Журнал».

Как программа устроена внутри — в [TECHNICAL.md](TECHNICAL.md).

## Ограничение ответственности

Приложение снижает риск, но не гарантирует полную защиту. Безопасность ваших аккаунтов зависит от многих других
факторов, не связанных с приложением: правил самих сервисов, данных и истории аккаунта, способа оплаты, откуда и как
вы им пользуетесь.
