# Proxy Tunnel

Небольшая программа для Mac и Windows. Она соединяет ваш компьютер с вашим собственным сервером за границей
и отправляет через него Claude и сайты, которые вы выберете. Всё остальное — банки, почта, видео, любые другие
сайты и программы — работает как обычно.

## Что понадобится

- Компьютер с macOS 13 или новее либо с Windows 10 или 11.
- Свой сервер за границей с Ubuntu или Debian. Если сервера нет, в программе есть кнопка «Арендовать сервер».
  После аренды хостинг пришлёт адрес сервера (несколько цифр через точку) и пароль от пользователя `root` —
  они понадобятся один раз, при первой настройке.

## Установка

**Mac**

1. Скачайте программу по ссылке в конце страницы и откройте скачанный файл.
2. Перетащите значок «Proxy Tunnel» в папку «Программы».
3. Первый запуск: в «Программах» щёлкните по «Proxy Tunnel» правой кнопкой мыши → «Открыть» → «Открыть».
   Если такой кнопки нет: попробуйте открыть программу, затем зайдите в «Системные настройки» →
   «Конфиденциальность и безопасность» и нажмите «Всё равно открыть».

Значок программы появится вверху экрана, справа, рядом с часами.

**Windows**

1. Скачайте программу по ссылке в конце страницы и запустите скачанный файл.
2. Если Windows покажет окно «Система Windows защитила ваш компьютер», нажмите «Подробнее» →
   «Выполнить в любом случае».

Значок программы появится внизу справа, рядом с часами. Если его не видно, нажмите на маленькую стрелку «^»
рядом с часами.

## Первая настройка (один раз)

1. При первом запуске откроется окно настроек. Впишите адрес сервера.
2. Подождите пару секунд. Если программа напишет «Вашего ключа на сервере нет», введите логин `root` и пароль
   от сервера. Галочку «Создать ключ для входа…» оставьте — тогда пароль больше не понадобится.
3. Нажмите «Настроить сервер» и подождите минуту-две, пока все пункты станут зелёными.

Программа сама всё установит на сервер. Пароль она нигде не сохраняет.

Когда всё готово, в разделе «Доступ к серверу» можно нажать «Выключить вход по паролю» — так сервер будет
защищён надёжнее, а программа продолжит входить на него сама.

## Как пользоваться

- **Включить:** щёлкните по значку программы и нажмите на верхнюю карточку «Туннель выключен». Зелёный значок
  и надпись «Claude — через туннель» — всё работает.
- После включения закройте и снова откройте Claude Code (в VS Code или в терминале) и браузер, если они были
  открыты.
- **Выключить:** снова нажмите на верхнюю карточку. При выходе из программы всё тоже возвращается как было.

При каждом запуске программа начинает с выключенного состояния — включайте, когда нужно.

## Что идёт через сервер

- **Claude** — сайт claude.ai, приложение Claude, Claude Code в VS Code и в терминале. Ничего дополнительно
  настраивать не нужно.
- **Сайты из списка.** Список — в настройках, раздел «Через туннель». Чтобы добавить сайт, впишите его адрес
  (например, `example.com`) отдельной строкой и нажмите «Сохранить». Если сайт открывается не полностью,
  добавьте и адреса, с которых он подгружает картинки и остальное. После изменения списка может понадобиться
  перезапустить браузер.
- **Всё остальное** работает напрямую, как без программы.

Список действует на браузеры и приложения, которые берут сетевые настройки из системы. Программы со своими
настройками сети (например, некоторые расширения для VS Code или утилиты в терминале) список не учитывают.

## Если что-то не так

- В окне программы под красным пунктом написано, что случилось и что сделать.
- «Сервер отклонил подключение» сразу после настройки — подождите полминуты и нажмите «Проверить».
- Claude Code перестал отвечать — проверьте, что программа запущена и туннель включён, либо выключите туннель
  и перезапустите Claude Code.
- Программа закрылась неожиданно — просто запустите её снова: при запуске она сама наводит порядок.
- Подробности о работе программы — в журнале: значок программы → «Журнал».

Как программа устроена внутри — в [TECHNICAL.md](TECHNICAL.md).
