# Proxy Tunnel

Приложение в строке меню macOS: держит SSH-туннель к своему зарубежному серверу и пускает через него только
выбранные домены (по умолчанию Claude, Anthropic и Threads). Остальной трафик, включая российские сервисы и
банки, идёт напрямую. VPN не нужен и не мешает: в режиме «VPN» приложение просто снимает свои настройки.

## Как устроено

```
Мак                                              сервер (Ubuntu/Debian)
Claude Code ── HTTPS_PROXY ─┐
браузер, Claude.app ── PAC ─┤
                            └─ 127.0.0.1:8888 ══ ssh -L ══ tinyproxy 127.0.0.1:8888 ── интернет
```

- **Сервер универсальный**: на нём только tinyproxy, слушающий `127.0.0.1`, и пользователь `tunnel`, которому
  разрешено одно — проброс на этот порт (`restrict,port-forwarding,permitopen=…` в `authorized_keys`,
  `ForceCommand nologin`). О Claude сервер ничего не знает. Скрипт установки — `Config.serverScript`.
- **На Маке** приложение запускает `/usr/bin/ssh -N -L` дочерним процессом и переподключает его с паузой
  (`Tunnel.swift`), раздаёт PAC-файл из памяти на `127.0.0.1:8889` (`PacServer`) и в режиме «Туннель»
  включает этот PAC для сетевой службы и пишет `env.HTTPS_PROXY`/`NO_PROXY` в `~/.claude/settings.json`
  (`Model.swift`, `ClaudeSettings`). Другие ключи этого файла не трогаются, перед записью делается `.bak`.
- PAC без запасного `DIRECT`: нет туннеля — эти домены не открываются вовсе, а не уходят с российского адреса.
- Проверка (кнопка «Проверить», фоном каждые 2 минуты): ssh жив, порт отвечает, `claude.ai/cdn-cgi/trace`
  через туннель видит адрес сервера и не RU, PAC включён и раздаётся, прокси прописан в Claude Code.

## Что где лежит на Маке

Не в репо — у каждого пользователя своё:

- `~/Library/Application Support/Proxy Tunnel/config.json` — сервер, порты, интерфейс, сетевая служба, домены;
- `~/Library/Application Support/Proxy Tunnel/id_ed25519` — ключ туннеля (создаётся кнопкой «Создать ключ»);
- `…/known_hosts` — ключ сервера, запоминается при первом подключении;
- `~/Library/Logs/Proxy Tunnel.log` — журнал ssh.

## Сборка и установка

```bash
menubar/build.sh                       # swiftc, Intel + Apple Silicon, подпись ad hoc → menubar/build/Proxy Tunnel.app
open "menubar/build/Proxy Tunnel.app"  # или скопировать в /Applications
```

Нужны Command Line Tools (`swiftc`), macOS 13+. Xcode-проекта нет. Тестов нет: проверка — сборка и
`bash -n` скриптов.

Первый запуск сам открывает настройки: создать ключ → «Скопировать команду для сервера» → выполнить её на
сервере под root (дождаться «сервер готов») → вписать адрес → «Сохранить» → переключить на «Туннель» и
перезапустить Claude.

## Скрипты

Работают с настройками приложения, без него не нужны:

- `check.sh` — те же проверки из терминала; последняя строка «МОЖНО»/«НЕЛЬЗЯ», код выхода 0 — можно;
- `mode.sh tunnel | vpn` — тот же переключатель режима; без аргумента показывает текущий.
