# Proxy Tunnel — для ИИ-агентов

- **Человек просит установить, настроить программу или разобраться, почему она не работает** — ведите его по
  [AI-SETUP.md](AI-SETUP.md): по одному шагу, на его языке, пароль от сервера — только в окно программы, не в чат.
- **Нужно изменить код** — [TECHNICAL.md](TECHNICAL.md): устройство, сборка (`menubar/build.sh` для Mac;
  Windows собирается только GitHub Actions, `.github/workflows/windows.yml`), проверка — сборка и `bash -n`
  на скриптах, тестов нет. Текст для людей — [README.md](README.md), простым русским.
